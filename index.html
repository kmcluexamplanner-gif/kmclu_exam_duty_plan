Semester Examination Duty Planner

Automatically distribute invigilation duties fairly among teachers.

Before using: This tool runs locally in your browser. It does not upload names anywhere. Review the generated chart and adjust it for leave, subject conflicts, accessibility, and university rules before issuing the final duty order.

1. Teacher list

Enter one teacher name per line. You can paste a list from Excel.

2. Examination schedule

Enter one date/session per line. Add the session time after the date if needed.

Each session uses the rooms listed above. The planner assigns the selected number of teachers to each room.

Your duty chart will appear here after you select Generate duty chart.
Fairness method: teachers are assigned in a shuffled, least-assigned-first order to balance total duties. Same-day repeats are avoided where possible. This is an assistance tool, not an official university allocation system.
